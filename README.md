# rs-toxcore-c

Rust bindings for [c-toxcore](https://github.com/TokTok/c-toxcore), and the
apps built on them.

This project is a component of the
[toktok-stack](https://github.com/TokTok/toktok-stack) monorepo.

## Project Structure

-   `toxcore/`: High-level, idiomatic Rust wrapper for the Tox API, on top of
    raw FFI bindings generated by `bindgen`. Targets are defined in the
    `rs-toxcore-c` package.
-   `toxxi/`: A terminal Tox client (TUI) with built-in Rhai scripting support.
-   `apps/groupbot/`: A Tox bot that bridges a conference and a group chat.

## Usage

The library can be used by adding it to your `deps` in Bazel from the monorepo
root:

```python
deps = ["//rs-toxcore-c:toxcore"]
```

## Building

Build the core library using Bazel from the monorepo root:

```bash
bazel build //rs-toxcore-c:toxcore
```

Run tests for the entire suite:

```bash
bazel test //rs-toxcore-c/...
```
